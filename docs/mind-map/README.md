# Mapa Mental de Testes - ServeRest

## Objetivo

O mapa mental foi criado durante a fase de planejamento dos testes com o objetivo de identificar funcionalidades críticas, cenários positivos e negativos, validações, requisitos de autenticação, segurança, performance e concorrência da API ServeRest.

## Cobertura

O planejamento contempla:

### Login

* Login válido
* Login inválido
* Usuário inexistente
* Token inválido
* Logout

### Usuários

* Cadastro
* Consulta
* Atualização
* Exclusão
* Validação de parâmetros obrigatórios
* Validação de dados duplicados

### Produtos

* Cadastro
* Consulta
* Atualização
* Exclusão

### Carrinhos

* Criação
* Consulta
* Conclusão de compra
* Cancelamento

### Segurança

* Controle de acesso
* Autorização
* Autenticação

### Performance

* Testes de carga
* Testes de concorrência

## Benefícios

A utilização do mapa mental permite:

* Melhor visualização da cobertura dos testes.
* Identificação de riscos.
* Planejamento de cenários positivos e negativos.
* Rastreabilidade dos requisitos.
* Priorização dos testes.
