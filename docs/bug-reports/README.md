# Bug Reports

Esta seção contém exemplos de defeitos identificados durante a execução dos testes da API ServeRest.

## Objetivo

Demonstrar o processo de registro, análise e documentação de defeitos seguindo práticas utilizadas em equipes de Quality Assurance.

## Estrutura do Relatório

Cada defeito documentado contém:

* Identificador do defeito
* Título
* Módulo afetado
* Severidade
* Prioridade
* Pré-condições
* Passos para reprodução
* Resultado esperado
* Resultado obtido
* Evidências
* Status

## Integração com Jira

Os defeitos também serão registrados e acompanhados através do Jira para demonstrar rastreabilidade e gestão do ciclo de vida dos bugs.
