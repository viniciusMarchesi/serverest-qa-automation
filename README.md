# ServeRest QA Automation
Projeto completo de Quality Assurance contendo testes manuais, testes de API, automação web, BDD, testes de performance e CI/CD utilizando ferramentas amplamente utilizadas pelo mercado.

# 🚀 ServeRest QA Automation Portfolio

Projeto desenvolvido para demonstrar conhecimentos em **Quality Assurance (QA)** através da validação da API ServeRest utilizando testes manuais, testes de API, automação, BDD, testes de performance e integração contínua.

## 📋 Objetivo

O objetivo deste projeto é aplicar boas práticas de testes de software em um ambiente próximo ao encontrado em projetos reais, cobrindo diferentes níveis de validação e automação.

## 🎯 Escopo dos Testes

### 🔐 Login

* Login com credenciais válidas
* Login com credenciais inválidas
* Login com usuário inexistente
* Login com campos obrigatórios ausentes
* Validação de token

### 👤 Usuários

* Cadastro de usuários
* Consulta de usuários
* Atualização de usuários
* Exclusão de usuários
* Validação de regras de negócio

### 📦 Produtos

* Cadastro de produtos
* Consulta de produtos
* Atualização de produtos
* Exclusão de produtos
* Validações de dados obrigatórios

### 🛒 Carrinhos

* Criação de carrinhos
* Consulta de carrinhos
* Finalização de compra
* Cancelamento de compra
* Validações de consistência dos dados

### 🔒 Segurança

* Autenticação
* Autorização
* Validação de acesso não autorizado
* Validação de tokens inválidos

### ⚡ Performance

* Testes de carga
* Testes de estresse
* Testes de concorrência
* Análise de tempo de resposta

# 🧠 Estratégia de Testes

O projeto foi estruturado seguindo uma abordagem baseada em risco, priorizando funcionalidades críticas para o negócio:

* Login
* Cadastro de usuários
* Cadastro de produtos
* Carrinho de compras

A estratégia contempla:

* Testes positivos
* Testes negativos
* Testes de validação
* Testes de integração
* Testes de performance
* Testes de segurança
